# Interactive QA — 31 August 2026

Tested the local preview of the existing DanIA Táctica Site with synthetic data,
through browser controls, typing, clicking and dragging. No owner production
projects, messages, accounts, sharing policy or external services were changed.

## Reproduced and corrected

1. Startup aborted at an undefined `carryMenuEl` listener. Removed the unfinished,
   unconnected upstream carry block; regular board duplication remains intact.
2. Localization changed the keyboard protocol `Arrow` to `Flecha`. Restored the
   protocol and protected method-call key strings in the localization script.
3. Player names and numbers disappeared when switching fields. Text now enters
   scene state on input, and option rows are not rebuilt during focus transfer.
4. Resizing from 390 to 768 pixels produced a ResizeObserver delivery-loop error.
   Canvas fitting and segmented-control layout writes now run on the next frame.
   Repeated 390 → 768 → 1280 checks no longer displayed the error.
5. A 2.6-second sequence exported as a 6.789-second MP4. Recording now follows
   elapsed time, skips overdue intermediate frames, and releases capture tracks.
   The same sequence exported as a valid 2.596567-second H.264 MP4 after the fix.

## Browser checks completed

- Cold startup without new application console errors.
- Add/select/drag players; edit names and numbers; draw an arrow and zone; place a ball.
- Edit a Markdown note, duplicate a board and play a two-board animation to its end.
- Reload and reopen the saved project; names, numbers, objects and board count persist.
- PNG export: decoded and visually inspected, 2048 × 1582, labels and pitch present.
- Project backup: downloaded valid JSON containing the project, boards and player data.
- GIF export: decoded, 1040 × 938, 78 frames, 2.6 seconds.
- MP4 export: decoded, 1040 × 938, H.264; timing verified as described above.
- Responsive working surface at 390, 768 and 1280 pixels using an iframe harness.
- Mobile-width settings, light/dark selection, scrolling and return to the editor.

The temporary viewport harness is not included in the published source.
Browser download-event reporting timed out, but the actual synchronized files
were inspected; no download implementation was changed because of that tooling issue.

## Automated checks and scope limits

Adaptation tests cover unresolved client identifiers, preserved action hooks,
keyboard protocols, text field updates, resize scheduling and video timing. The
selected upstream suite covers project storage, notes, geometry, GIFs and ZIPs.

This is not a guarantee of zero defects. Physical Android/iOS/Surface touch,
stylus behavior, very large projects, image import/restore end to end and every
advanced upstream option have not been fully tested. Some advanced labels remain
in English. Account services and cloud synchronization are intentionally absent
in this self-host adaptation. JSON backups do not include all local background
image bytes: original background images should be kept separately.
